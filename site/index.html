Model assumptions

1. Choose a scenario

Illustrative starting points, not calibrated recommendations. Presets reset core assumptions and disable custom weights. Run each scenario to compare win chances.

2. Field strength & uncertainty

Round-to-round score uncertainty. Start at 2.8 strokes; try 2.5–3.5 to test sensitivity. Higher values allow more upsets. This is not a course-difficulty score.

Start at 20 rounds. Try 30–40 when you want to temper short histories. Higher values pull players with fewer recorded rounds toward average.

Start at 1.0× for history alone, or 0.5× with stat weights. Zero removes history; larger values amplify past-performance differences.

Use 5,000 for exploring; 25,000 for less sampling noise. More runs do not improve the underlying assumptions.

3. What skills matter?

Fine-tune skill categories

Weights add each stat's gap to the field average on top of score history. All start at zero. Stats overlap with history and with each other (SG: Total includes the categories), so stacking them double-counts. Players without data count as field average. Counts such as 107/147 show data coverage, not rankings. At 0 a stat has no effect; 0.5× counts half its strokes-gained gap. For other stats, 0.2 means a 0.2-stroke benefit per round for a player one standard deviation (SD) better than average.

Custom fields

Add your own rating, like course history or a power ranking. Paste one Player name, value per line. Values are standardized against the players you list. Start at 0 weight, then try 0.1–0.3 strokes per SD for a small effect. Saved in this browser only.

4. A player-specific hypothesis

Player adjustments

Start at 0. Negative improves this player’s expected score. Try −0.3 for a modest breakout hypothesis or +0.3 for a setback; these are assumptions, not measured effects.

Start at 1.0×. Try 1.2× to model greater uncertainty for the selected player. This changes the spread, not expected skill.

Each refresh replays the rest of the tournament thousands of times from the official scores. A player’s remaining holes are drawn around the field’s average score per hole this week plus their model skill ÷ 18, with round variation scaled by √(holes left ÷ 18). Cut and withdrawn players can’t win. Ties after 72 holes go to a simulated sudden-death playoff. Scores come from ESPN’s public scoreboard and can lag the broadcast.

Player model breakdown

Choose a player to see the calculation.

Effect is this player's change in expected strokes per round from each weighted field. Negative is better. Each tournament score is drawn from a normal distribution with this expected round score × 4 and standard deviation equal to round variation × 2, with the selected player’s variation multiplier applied. A lower score wins. This is mathematically equivalent to adding four independent normally distributed rounds.

Know the limits. The pre-event model doesn't include cuts, playoffs, weather, injuries, or late field changes; the live model knows who made the cut and simulates playoffs but not weather, tee-time waves or hole-by-hole difficulty. The original forecast used 2022–2026 score data available before the event. Strokes-gained, traditional, form and course-fit stats come from PGA Tour's unofficial stats feed and are not fitted to results. The weights are your assumptions, not tested predictors. Experiment results are local to your browser and are not saved forecasts or betting advice.
