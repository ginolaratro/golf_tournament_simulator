From past scores to a forecast

1 · Past rounds

Compare each historical round with that tournament round's field average.

2 · Player estimate

Average those differences, pulling estimates with fewer rounds toward the field average.

3 · Play it again

Draw four random rounds per player. The lowest simulated total wins.

4 · Count winners

Repeat for the full field, then divide each player's wins by the number of simulations.

The model uses a fixed round-to-round spread for every player. It does not model cuts, playoffs, course changes, weather, or late field changes. These are model estimates, not guarantees.

Against real life

When the event is final, run the score command and rebuild this report to show its result. Each saved forecast is a local snapshot.
